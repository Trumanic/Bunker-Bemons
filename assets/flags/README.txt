Country flags (4:3 SVG), named by lowercase country code: ma.svg, us.svg, sa.svg ...
Also available: gb-eng, gb-sct, gb-wls, gb-nir, eu, un, xk (Kosovo).

Set a player's country in data/players.json with the two-letter code, e.g. "country": "MA".
