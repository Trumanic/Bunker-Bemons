Profile pictures for the leaderboard.

Option 1 (recommended): put the image in this folder and set it in data/players.json:

    "Amine": { "country": "MA", "pfp": "amine.png" }

A full link also works: "pfp": "https://example.com/amine.png"

Option 2: no setting needed. Name the image after the player in lowercase:

    amine.png   voicechatping.jpg   robianny.webp

Supported formats: .png  .jpg  .jpeg  .webp
Players without an image show the first letter of their name instead.
Square images look best (they are cropped to fill the square).
